# Reportar una vulnerabilidad

No publiques detalles explotables, credenciales ni datos de usuarios en un
issue o pull request público.

Si GitHub Private Vulnerability Reporting está habilitado para este repositorio,
envía el reporte mediante **Security → Report a vulnerability**. Si no está
habilitado, contacta en privado a sus mantenedores antes de divulgar detalles;
no uses un issue público para información sensible.

Incluye el componente afectado, el impacto, las condiciones necesarias para
reproducir el problema y una mitigación sugerida si la conoces. No incluyas
tokens, documentos de proveedores ni datos personales en el reporte.

Este es un proyecto académico sin garantía de soporte ni tiempos de respuesta.
